Songs & formats

One library, several engine layouts.

Blockified scans lightweight local songs, installed complete packs, configured Mods directories, and—when applicable—the active bundled world’s owning pack.

Psych / legacySection-based chart JSON, separate difficulties, embedded or standalone events.
V-SliceChart and metadata pair with all declared difficulties and split-vocal support.
CodenameModern chart notes, BPM data, events, and time-signature conversion.
Story ModePsych weeks, ordered song playback, difficulty lists, artwork, unlock metadata, and saved total scores.

When the chart editor saves a modified external chart into config/fnfmod/songs, original_directory.txt links it to the exact source. The local chart and optional local audio/events win; missing assets and difficulties continue to come from that source.

Characters & visuals

Psych art and Minecraft performers can coexist.

BBS animation sets

Named JSON definitions map idle, directions, misses, hey, and custom actions to BBS form-state IDs. Optional -opp.json files override only opponent-side data.

Psych characters

FNF mode reads Psych character JSON, Sparrow XML atlases, stage positions, camera offsets, icons, health colors, vocal prefixes, and single- or double-idle behavior.

World sprites

Gameplay Lua sprites and 2D characters assigned to the world camera use client-side entity hosts for world position, lighting, collision, gravity, shadow blobs, and IRLights shadow compatibility.

Screen-space outlines

setObjectBorder outlines supported Lua objects, vanilla entities, and BBS forms in fixed Psych-canvas pixels, so thickness does not change with window resolution.

Note artwork

Note skins support normal and pixelUI assets, Sparrow XML or XML-less pixel sheets, natural source-resolution sizing, optional RGB-template recoloring, and per-part transforms. Hit splashes and hold covers use separate selectable pack layouts; skins may bundle either effect and take priority.

Creator tools

Most authoring stays inside the game.

Chart Editor

Charts notes, sustains, sections, note types, BPM, meters, and events. Includes waveforms, transient markers, metronome, loop regions, bookmarks, stem controls, tap tempo, and playtesting from the timeline.

Character Editor

Loads and saves player and opponent mappings together, previews BBS forms and states, edits health color and camera offsets, bundles forms, and imports missing forms into BBS.

Free Camera

During a machine-based Chart Editor playtest, press Ctrl + Shift + Space to create or edit sprites, texts, characters, and camera events with Blender-inspired movement, numeric fine tuning, transform resets, Lua copy/paste, normal/orbit camera tabs, and a stage camera marker.

Note Settings & NoteSkin Editor

Note Settings uses a live chart-and-audio preview for everyday asset choices, lane colors, and delay. The Creator Tools editor uses those saved settings as its preview while editing skin JSON transforms and RGB support.

Machines & worlds

The machine is an entry point, not a limitation.

Physical machine

A placed Funkin’ Machine stores a selected profile. Profiles can replace every texture face and run a Lua-built interface from the owning mod.

Virtual machine

The Designer creates a persistent non-colliding hitbox entity and a protected invisible anchor. Precise mode fits non-full geometry; Full Blocks snaps the region to the block grid.

Chunk Loader Points

Invisible points keep a square of ticking chunks loaded with radius 0–12. Create and reveal them with the Funkin’ Designer; gameplay Lua can temporarily control their tagged properties.

Bundled worlds

Worlds inside mods/<pack>/worlds run in place. Their blockified-options.json can control cheats, saving, external content, forced options, and bundled BBS model assets.

Lua & events

Two runtimes serve different jobs.

During songs

Gameplay Lua

A sandboxed Psych Engine 1.0.x compatibility runtime with lifecycle, note, input, camera, sound, sprite, text, save-data, custom-substate, and Blockified world APIs.

Inside machines

Machine-menu Lua

A separate fixed-canvas UI runtime with widgets, graphs, animated sprites, fonts, layers, tweens, timers, audio, multiple screens, song/week data, and persistent machineData.

Chart events share the same timeline as imported Psych events. Blockified adds Minecraft Command, persistent camera zoom/focus/behavior, 3D camera rotation and orbit, directional shading, and extra-character creation/removal/tweening.

Multiplayer & safety

The server stays authoritative.

The first machine user selects and hosts; a second player may join the opponent side. The host’s song, difficulty, presentation mode, and asset policy are authoritative.

  • Dedicated servers expose server-installed songs and transfer chart, event, and audio data when clients need it.
  • Dedicated-server gameplay disables Lua and rich executable mod assets. LAN keeps local scripting and machine menus.
  • Transfers validate file count, bounded names and chunks, declared size, and SHA-1 before cache use.
  • Custom machines are singleplayer/LAN only. LAN guests need matching machine content; assets are not streamed.

Rollback

Songs temporarily borrow the world.

A song snapshots participant state and journals synchronous block mutations made by chart/Lua commands. Finish, quit, loss, cancellation, restart, disconnect, and editor playtest cleanup all use the same restoration path.
