01

Install Blockified

Blockified runs on Minecraft 1.21.1 with NeoForge 21.1.0+. It uses BBS FS for forms and animation, with Sinytra Connector and Forgified Fabric API providing the compatibility layer.

Required mod BBS FS Forms and animation runtime Open mod page ↗ Required mod Sinytra Connector Fabric compatibility layer Open mod page ↗ Required mod Forgified Fabric API NeoForge-compatible Fabric API Open mod page ↗
  1. 1

    Install the required mods

    Put Blockified, BBS FS, Sinytra Connector, and Forgified Fabric API into the same NeoForge 1.21.1 instance.

  2. 2

    Open a world

    Blockified creates its folders below config/fnfmod. The Functional Blocks creative tab contains the Funkin’ Machine and Funkin’ Designer. Chunk Loader Points and hitbox-less virtual machines are placed through the Designer’s Blocks tab.

  3. 3

    Place a Funkin’ Machine

    Right-click the machine to open the Song Menu. Freeplay, Story Mode, and Settings are available from this screen.

02

Choose a content type

Use a lightweight song for the smallest chart-and-audio layout. Use a complete pack when the song owns images, stages, custom events, characters, machines, or bundled worlds.

Fastest start

Lightweight song

Lives in config/fnfmod/songs/<song>. Accepts chart JSON, events.json, OGG audio, V-Slice metadata JSON, and song-local Lua.

Full creation

Complete mod pack

Lives in config/fnfmod/mods/<mod>. Keeps Psych, V-Slice, Codename, or Blockified-style assets together.

Important boundaryA lightweight song may run its own Lua and the naked global mods/scripts scripts, but it does not gain a complete pack’s rich asset namespace. Move the project into a complete pack when it owns images, characters, fonts, stages, or machines.

03

Create a song

Make a folder named after the song. The instrumental is required; vocals may be combined or split by performer.

config/fnfmod/songs/my-song/
├─ my-song.json
├─ my-song-hard.json        optional difficulty
├─ Inst.ogg                 required
├─ Voices.ogg               combined vocals, or
├─ Voices-Player.ogg        split player vocals
└─ Voices-Opponent.ogg      split opponent vocals

For V-Slice, use my-song-chart.json and my-song-metadata.json. Every difficulty inside the chart becomes selectable. Blockified also recognizes lowercase audio names and performer-specific vocal prefixes.

Importing audioChoose Song Audio can select several files. Recognized names become the correct stems; other audio formats are converted to OGG through FFmpeg without changing the source files.

04

Chart and playtest

From a Funkin’ Machine’s Song Menu, press 8 and choose Chart Editor. You can also run /fnf editor [song], although commands require cheats in singleplayer or operator permission on a server.

ClickPlace or remove a note
Shift + ClickSelect notes
E / QLengthen or shorten sustain
DeleteDelete selection
A / DPrevious or next section
SpacePlay or pause audio
Ctrl + SSave to assigned or normal song folder
Shift + EnterPlaytest from the chosen point
Ctrl + Shift + SpaceToggle Free Cam during a machine-based playtest

The editor supports beat snap, independent grid zoom, BPM and time-signature changes, stacked events, custom note types, waveforms, onset markers, metronome, loop playback, bookmarks, stem mute/solo, charting offset, and readable Psych-format saves.

Two offsetsSong offset affects saved charts and gameplay. Charting offset is editor-only and changes playback, waveforms, metronome, and grid alignment without changing gameplay timing.

05

Build a complete pack

Install the pack as one folder. Existing Psych-family layouts can stay largely unchanged; Blockified-specific folders extend them.

config/fnfmod/mods/My-Mod/
├─ pack.json                Psych pack metadata
├─ data/<song>/             charts and song Lua
├─ songs/<song>/            audio
├─ scripts/                 global Lua
├─ stages/                  stage JSON and Lua
├─ custom_events/
├─ custom_notetypes/
├─ animations/              BBS form/state mappings
├─ characters/
├─ images/  sounds/  fonts/
├─ machines/                machine profiles and menus
├─ weeks/                   Psych Story Mode weeks
└─ worlds/<world>/          bundled Minecraft worlds

pack.json and pack.png supply Psych-style identity. V-Slice packs may instead use _polymod_meta.json and _polymod_icon.png. Mods settings can also point directly at a pack or at a container holding several packs.

Bundled-world scopeInside a world stored under a pack’s worlds folder, only the owning pack is exposed by default. Ordinary singleplayer and LAN worlds can use all installed packs, lightweight songs, and configured Mods directories.
