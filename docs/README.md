# Blockified Engine documentation

Static, dependency-free GitHub Pages documentation, creation guides, and wiki
for Blockified-specific behavior.

- Open `index.html` through a local HTTP server for preview.
- Edit the landing page in `index.html` and the three content pages in
  `guide.html`, `wiki.html`, and `documentation.html`.
- Edit shared content-page navigation/search behavior in `section.js` and browser
  zoom persistence in `site-zoom.js`.
- Edit shared content-page presentation in `section.css`; the landing page keeps
  its presentation inline so its intro and bubble transitions remain self-contained.

The Pages workflow deploys this directory. All links are relative so every page
works under the repository's GitHub Pages subpath.
