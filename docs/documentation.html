Reference / Chart events

Built-in chart events

Events may run on the timeline or before the song. Custom event files are discovered from the active pack’s custom_events folder.

Minecraft CommandBlockified

Runs a Minecraft command. Value 1 is the command; the Chart Editor's Value 2 toggle chooses Player or Server.

Placeholders include <player>, <opponent>, <speakers>, camera-relative directions such as <forward:2,left:1>, <camera_rotation>, and <character_rotation:degrees>.

Camera ZoomBlockified

Persistent zoom. Values: amount -1..0.9, duration in seconds, easing. Amount 0 restores normal zoom.

Camera FocusBlockified

Overrides section focus. Value 1 accepts player/BF, opponent/Dad, GF/speakers, or an extra-character tag; Value 2 is easing. Empty focus restores Must Hit behavior.

Camera BehaviorBlockified

Minecraft and Legacy only. Values: focus speed multiplier, easing, and whether sing/animation camera offsets are enabled. Empty values restore defaults.

Camera Follow PosHybrid

Values 1–2 retain Psych screen coordinates. Extended values add 3D right/up/forward offsets, easing, override mode, machine/camera reference frame, and move duration.

Camera Rotation 3DBlockified

Values: pitch, yaw, roll, easing, duration, and layer. The normal/orbit layer moves around an active pivot; camera/view/local rotates the view independently.

Camera OrbitBlockified

Values: on/off, follow/pin, pivot X/Y/Z, pivot duration, and easing. Camera Follow Pos supplies the radius/position; Camera Rotation 3D animates around the pivot.

Directional ShadingBlockified

Value 1 controls block/fluid directional shading and ambient occlusion. Value 2 controls vanilla entity shading. Both restore when the song exits.

Add CharacterBlockified

Values: unique tag, animation definition, stage X/Y/Z, extra yaw, and initial animation plus player/opponent definition side.

Remove CharacterBlockified

Value 1 removes the matching extra-character tag.

Tween CharacterBlockified

Values: tag, target X/Y/Z, duration, easing, and optional target yaw. Empty coordinate components retain their current values.

Reference / Gameplay Lua

Gameplay Lua

This section documents the difference between Psych Engine 1.0.4 Lua and Blockified—not the Psych API itself. Ordinary Psych sprite, text, animation, property, timer, sound, input, and callback syntax is omitted when Blockified does not change it.

Compatibility baselineBlockified recognizes most common Psych 1.0.4 gameplay Lua calls, but implements them against Minecraft and its own renderer. The entries below are additions, changed behavior, or unsupported Psych features.

Script-discovery differences

Psych’s normal scripts, stages, custom_notetypes, custom_events, and data/<song> locations remain supported. Blockified adds these cases:

mods/scriptsglobal

The naked installed-mod scripts remain active for eligible standalone/lightweight songs instead of depending on the song’s source folder.

scripts/stagesfallback

Stage Lua may also live in data/stages or assets/stages, in addition to Psych’s normal stages folder.

songs/<song>extra

Lua stored beside Inst.ogg and the voice stems is loaded.

<song folder>extra

Top-level Lua in a resolved standalone song folder is loaded after pack scripts.

Psych character scriptsBlockified does not currently auto-load characters/<character>.lua. Put that behavior in a pack script, stage script, or song script instead.

World-space objects and characters

Psych’s game, hud, and other cameras remain on the fixed 1280×720 canvas. Blockified adds the world camera for Minecraft/Legacy stage space.

setObjectCamera(tag, 'world')

Moves a Lua sprite or text object into 3D stage-local space with real depth.

makeLuaSprite(...[, z]) makeLuaText(...[, z])

Static sprites accept an optional fifth Z argument; text accepts an optional sixth. Animated sprites set Z through setProperty(tag .. '.z', value).

setObjectRotation(tag, pitch, yaw, roll)

Adds three-axis rotation. Rotation and XYZ scale properties also work on supported main characters, extra characters, and BBS forms.

setWorldSpriteBillboard/Lighting(tag, enabled)

Controls camera-facing and Minecraft light response.

setWorldSpriteGravity/Collision/Shadows(tag, enabled)

Adds client-side entity physics, collision, and vanilla blob shadows during gameplay.

setWorldSpriteIRLightsShadows(tag, enabled)

Adds IRLights projected-shadow participation; enabled by default.

setObjectSeeThrough(tag, enabled)

Lets a world object render through Minecraft geometry.

setObjectBorder(tag, size, color, style)

Adds a fixed-Psych-resolution outline to Lua sprites and performer characters, including BBS forms.

World sprites are backed by client-side entities during gameplay so physics and lighting integrations can see them. Free Cam continues using its editor renderer.

Layers, masks and parenting

Gameplay and machine-menu Lua share Blockified's gradient, mask, clipping, and blend APIs. They work on flat Lua objects in 2D or 3D, including animated sprites, text, menu widgets, and extra 2D characters. They are not arbitrary Psych shader support or effects on BBS 3D meshes.

makeLuaGradient / ui.gradient

Create a standalone linear, radial, or angular gradient, including color and alpha stops. It can be drawn normally or used as a mask.

setObjectGradient(tag, type, stops, angle)

Apply a non-destructive gradient to existing pixels. Up to 16 color/alpha stops; geometry and strength are tweenable.

setObjectMask(target, source, mode, inverted, hideSource)

Alpha masks use opacity (opaque black reveals); luminance masks use brightness (white reveals, black hides). Masks remain local to the target, with editable offset, scale, rotation and softness.

setBlendMode(tag, mode)

Normal, add, multiply, screen, subtract, lighten, darken, difference, and overlay now have distinct rendering in both Lua runtimes, including depth-tested world planes.

setObjectClip(tag, type, x, y, width, height, radius, softness)

Normalized local rectangle, ellipse, or rounded-rectangle clipping without rescaling the source.

makeLuaGroup / ui.group

Composite child layers before applying group opacity/effects. Add members with addToGroup(group, child). These are flat visual composites, not interactive child-widget containers.

setObjectParent(child, parent, keepPosition)

Transform-only attachment for gameplay Lua objects or menu widgets. By default the child's X/Y/Z become zero at its parent's center. Its own offsets stay editable; parent movement, rotation and scaling carry it along. Use true to preserve its current placement instead.

removeObjectParent(child, keepPosition)

Detach; placement is preserved by default. getObjectParent(child) returns the current parent ID. Extra performers and BBS/vanilla entities do not participate in this hierarchy.

doTweenEffect(tag, object, property, target, duration, easing)

Tween numeric gradient, mask, and clipping properties using the runtime's usual clock and callbacks.

The Menu Lua Editor's Effects tab exposes these controls and saves ordinary Lua. Parented screen widgets use local pixels, not normalized coordinates; world widgets use local blocks. Full signatures, examples, limits, and performance notes.

Other Blockified additions

setRenderDistance(chunks) getRenderDistance()

Temporarily changes render distance, clamped to Minecraft’s 2–32 range and restored after gameplay.

setFOV(value) getFOV()

Changes the base Minecraft FOV for the song; camera zoom remains multiplicative.

setHudStyle(style) getHudStyle()

Changes or reads the active HUD style during gameplay. showTimeBar(visible) controls the native time bar.

runMinecraftCommand(command[, source])

Runs through the same permission-aware path as the chart event. Source defaults to player; server still requires authority. runCommand is an alias.

cameraOrbit(pinned, x, y, z, duration, easing)

Starts or updates the world-camera pivot. Follow mode offsets the focused character; pinned mode uses absolute stage-local XYZ. startCameraOrbit is an alias and stopCameraOrbit() ends it.

setCameraFollowPoint(x, y) addCameraFollowPoint(x, y)

Sets or offsets the Psych-compatible camera follow point. Scroll equivalents are setCameraScroll and addCameraScroll.

setCameraBopEnabled(target, enabled)

Controls game, HUD, or both beat bops. Read it with getCameraBopEnabled(target).

addBlockifiedCharacter(tag, character, x, y, z, yaw, animation, side)

Adds a named BBS or 2D performer in Minecraft/Legacy presentation. makeBlockifiedCharacter is an alias.

changeBlockifiedCharacter(tag, character, side)

Changes an existing extra performer without replacing its tag. Existence, remove, reset-position, all-collision, and all-shadow helpers are also available.

getBlockShading() getMobShading()

Reads current directional-shading state. Change it through triggerEvent('Directional Shading', ...).

doTweenZ / doTweenRotationX/Y/Z

Extends Psych tweens with depth and three-axis rotation. doTweenAngleX/Y/Z are aliases. All unchanged Psych tween/timer/audio calls keep their normal names and are not repeated here.

setTextQuality / setTextLineSpacing / setTextLetterSpacing

Adds font oversampling quality and explicit line/letter spacing, with matching getters.

achievementExists / unlockAchievement / achievement score calls

Adds Blockified-backed achievement storage helpers.

Timing, events, and note assets

curMeterBeat curBeatInMeasure curMeasure

Adds time-signature-aware counters. timeSignatureNumerator and timeSignatureDenominator expose the current meter.

onMeterBeatHit(beat, numerator, denominator)

Runs when the beat inside the current measure changes.

onMeasureHit(measure)

Runs at the start of each measure.

triggerEvent(name, value1, ... value7)

Blockified extends the Psych dispatcher with additional value slots for its larger camera/world events.

custom_notetypes texture access

A custom-note script may expose only the exact atlas names assigned through texture or noteSplashData.texture when general pack images are unavailable in Minecraft presentation.

onStartCountdown()

Unlike Psych, Blockified currently treats this as a setup notification. Returning Function_Stop does not hold the countdown.

Known differences from Psych

No Haxe execution

runHaxeCode does not execute arbitrary Haxe. HScript registration/calls, Haxe libraries, arbitrary method calls, and runtime class creation are compatibility no-ops.

No GLSL shaders yet

Shader setters are compatibility no-ops and shader getters return typed empty values. Scripts should branch on shadersEnabled == false.

Limited pointer/controller API

Keyboard APIs work. Mouse-button reads are partial, mouse coordinates currently return zero, and gamepad APIs return false/zero.

No video/dialogue runtime

startVideo and startDialogue are registered so a port does not crash, but they do not open Psych substates.

No arbitrary Flixel groups

addToGroup, removeFromGroup, and updateHitboxFromGroup are not implemented. Use the supported note/strum groups and object order.

Unsupported engine transitions

loadSong, addCharacterToList, startCountdown, and setTimeBarColors are compatibility no-ops. Use Blockified events, menu APIs, or native song flow.

Restricted class access

getPropertyFromClass/setPropertyFromClass map selected ClientPrefs and PlayState fields plus FlxG.width/height. Other Haxe classes return nil.

Reduced startTween options

Multi-property and color tweening work, but only ease and startDelay options are read. Psych loop and ping-pong tween types are not reproduced.

Small missing legacy surface

Psych’s getCharacterX/Y, setCharacterX/Y, and addAnimationByIndicesLoop are not registered. Use properties and the loop argument of addAnimationByIndices.

Settings and presence

getModSetting reads the declared default because Blockified has no Psych mod-settings UI. Discord presence/client-ID calls are accepted but do nothing.

Safety and multiplayer

Each script has isolated globals. Lua’s process, environment, arbitrary filesystem, module loading, classloading, and dynamic-code surfaces—os, io, package, require, load*, dofile, debug, and luajava—are removed.

getTextFromFile / checkFileExists / directoryFileList

Read only inside the resolved song folder or its mod root; parent-path escapes are rejected.

saveFile / deleteFile

Write or delete only inside the resolved song folder. Save slots use Blockified’s sandboxed Lua-save storage.

5,000,000 instructions / 1 second

Each top-level chunk or callback has a runaway-script budget. Time spent inside trusted asset-loading host calls is excluded from the wall-clock limit.

Dedicated server

Gameplay Lua is disabled completely. Integrated singleplayer and LAN retain Lua, subject to the active mod/source permissions.

Reference / Machine-menu Lua

Machine-menu Lua

Machine menus use a fixed 1280×720 centered canvas. Normalized X/Y values from −1 through 1 scale with that canvas; larger values are pixels.

UI constructors

ui.label(id, text, x, y)

Text label.

ui.button(id, text, x, y, width, height)

Clickable button with function button:onClick().

ui.toggle(id, text, x, y, width, height)

Boolean control with onChange(value).

ui.slider(id, text, x, y, width, height)

Numeric control using mutable min, max, and value.

ui.panel(id, text, x, y, width, height)

Colored background panel. Its default color is translucent near-black.

ui.image(id, path, x, y, width, height)

Static image from the machine profile or owning mod.

ui.sprite(id, path, x, y, width, height)

Static sprite alias with angle and other sprite fields.

ui.animatedSprite(id, png, xml, x, y, width, height)

Sparrow XML animation with prefix animations and playback methods.

ui.graph(id, shape, x, y, width, height, color)

Rectangle, circle/ellipse, line, triangle, or polygon. ui.graphic is an alias.

ui.world(widget, x, y, z)

Moves any constructor into Minecraft’s 3D scene. Coordinates are block offsets from the menu origin, Y points up, and interactive controls remain clickable.

3D camera and zoom

camera.setPosition(x, y, z)

Immediately sets the absolute Minecraft camera position.

doTweenCamX/Y/Z(tag, value, duration, easing)

Tweens one position axis. Multiple axes can run together and completion calls onTweenCompleted(tag).

camera.setRotation(pitch, yaw, roll)

Immediately sets all three Minecraft camera angles.

doTweenCamRotationX/Y/Z(tag, value, duration, easing)

Tweens pitch, yaw, or roll using the same Psych-style argument order.

camera.lookAt(x, y, z)

Immediately aims the camera at a world point while retaining roll.

camera.setZoom(value) doTweenCamZoom(tag, value, duration, easing)

Changes or tweens the menu FOV multiplier: 1 is normal and larger values zoom in.

camera.getX/Y/Z() camera.getPitch/Yaw/Roll() camera.getZoom()

Reads the current, including in-progress tween, camera state. camera.reset() restores the entry view.

Navigation and song data

machine.openSongSelect(returnTo)

Opens the built-in selector; exit target may be menu, world, or selector.

machine.playSong(id, difficulty, options)

Starts a song. Set machine = 'stage_tag' to use a different hitbox-less virtual machine's position/facing, or omit it to use the menu's origin. Other options: duet, playAs, look, and returnTo. With a named stage, returnTo = 'menu' reopens the launching menu's main page, not the target's profile. machine.id/machine.tag continue to describe the menu's own origin.

machine.getSongs() machine.getSong(id)

Returns authoritative song IDs, display names, opponent icons, and difficulties.

machine.getWeeks() machine.getWeek(id)

Returns week identity, visibility, unlock, artwork, difficulty, character, and ordered-song metadata.

machine.openScreen(name)

Loads screens/<name>.lua inside the current machine profile. Use 'main' to return to menu.lua. Widgets/timers/tweens/page callbacks reset; machineData and tagged audio persist.

machine.openSettings()

Opens Blockified settings and returns to the Lua menu.

machine.openCharacterEditor()

Opens the Character Editor.

machine.openChartEditor(songId, difficulty)

Opens the Chart Editor, optionally at a chosen song and difficulty.

machine.setSongExitTarget(target)

Selects menu, world, or selector for finish, quit, or loss.

machine.saveData()

Immediately persists per-machine machineData.

machine.close()

Closes the Lua menu and releases its machine session. Disabled when the world requires autoOpenMenu.

machine.exitWorld()

Leaves the current world without a prompt, using Minecraft's normal disconnect/save lifecycle. Returns true when queued, false when unavailable or already requested. Disabled in the Menu Editor.

Escape opens Minecraft's pause menu directly on every Lua page. Resuming returns to that same page, without restarting its script or shared music.

-- machines/my-machine/menu.lua
local extras = ui.button('extras', 'Extras', 0.5, 0.5, 180, 24)
function extras:onClick()
    machine.openScreen('extras') -- machines/my-machine/screens/extras.lua
end
-- On the Extras page, use machine.openScreen('main') to return.
function play:onClick()
    machine.playSong('earrings', 'normal', {
        machine = 'earrings_stage', -- Designer tag on the hitbox-less virtual machine
        returnTo = 'menu'
    })
end

Place the target with the Designer's Blocks tools and give it a unique tag. It needs no custom menu profile or manual interaction. Tags are case-insensitive and scoped to the current dimension; allowed characters are letters, numbers, underscores, and hyphens (up to 64). Unknown, duplicate, removed, or busy targets show an error without starting the song. A true Lua return means the request was queued, not that server validation has finished.

Named stages support singleplayer/LAN mod worlds. Their index survives world saves and chunk unloads; older anchors register when their chunk next loads, so visit one once if it is not found after updating. Temporary stage chunk loading is released when the session ends. Omitting machine preserves the existing behavior; returnTo = 'world' and 'selector' also remain available.

Keyboard and cursor input

keyboardPressed(name)

True while a physical key is held. Uses Psych names such as A, SPACE, LEFT, SHIFT, F1, and NUMPAD1.

keyboardJustPressed(name)

True only during the update in which the physical key was pressed.

keyboardReleased(name)

True only during the update in which the physical key was released.

onKeyPress(keyName, keyCode, modifiers)

Fires once on physical press, without OS key-repeat callbacks. keyName is the stable Lua-facing name.

onKeyRelease(keyName, keyCode, modifiers)

Fires once when the physical key is released. Keyboard Lua is suppressed while an editable text box has focus.

cursor / getMouseX() / getMouseY()

Reads the fixed-canvas cursor position; mouse helpers and widget hover callbacks remain available alongside keyboard input.

onScroll(dy, dx)

Runs for wheel/trackpad input anywhere in the menu. Positive dy scrolls up; negative scrolls down. dx carries horizontal input. Lua decides which objects/properties to move.

function object:onScroll(dy, dx)

Runs on the topmost visible object under the cursor that defines this handler, before the global callback. Supports 2D and 3D hit testing; decorative objects without handlers let scroll input through.

getMouseWheel() / getMouseWheelX()

Polling alternative: accumulated vertical/horizontal deltas, also exposed as cursor.scrollY/cursor.scrollX. Reset after each onUpdate, page change, or pause. Reads do not consume input; do not multiply by dt.

local title = ui.label('title', 'Scroll me', 0.5, 360)
local targetY = 360
function onScroll(dy, dx)
    targetY = math.max(100, math.min(620, targetY + dy * 30))
    doTweenY('scrollTitle', 'title', targetY, 0.2, 'expoOut')
end

Widgets expose position, dimensions, color, alpha, visibility, order, and type-specific fields. Text widgets also support font, fontScale, and shadow. Available tweens include X, Y, width, height, alpha, angle, font scale, color, and menu blur.

Tutorials / Creator tools

Create without hand-editing every file

Right-click a Funkin’ Machine to open the Song Menu, then press 8 (the main keyboard or numpad key). Pressing 8 again returns to the Song Menu.

Chart Editor

Starts a new chart workspace at this machine. Because the editor remembers the machine position and facing, it can launch a complete world playtest and Free Cam.

Character Editor

Creates or edits the animation definition that maps FNF actions such as left and idle to BBS form states.

Reload Songs

Rescans songs, difficulties, weeks, and health icons after files are changed outside Minecraft. It does not save or rewrite those files.

Week Maker

Creates a Psych-compatible Story Mode week and its ordered song list.

NoteSkin Editor

Edits note artwork configuration with a playable chart preview. This is the advanced editor; normal Settings keeps only the everyday note options.

Menu Lua Editor

Visually edits a current-mod machine menu in 2D or 3D, including its Minecraft camera. Save updates a marked generated block inside menu.lua; handwritten callbacks and code outside that block remain untouched.

World Settings

Appears only while hosting a bundled mod world, unless that world hides the button. It edits that world’s blockified-options.json.

Chart and test a song

Select Chart Editor in Creator Tools. The six right-side tabs separate saved song data from editor-only aids:

SongSets the title, starting BPM and meter, gameplay scroll speed, gameplay offset, player/opponent IDs, vocal use, pixel UI, and exact song audio.
SectionControls who must hit, GF notes, alternate animations, section length, BPM or meter changes, and section copy, clear, side-swap, mirror, or duet operations.
NoteEdits one note’s exact time, sustain, and note type. Apply Selected Note commits all three fields to the active note; Apply Notetype to Selected changes only the type of every selected note.
EventsAdds, edits, removes, and stacks events at one timestamp. The dropdown includes built-in and discovered custom events; Event Help uses the custom event’s matching TXT documentation when present.
ChartingContains editor-only playback rate and offset, beat snap, Vortex mode, hitsounds, metronome and volume, loop points and pre-roll, three-tap BPM, stem mute/solo, and named bookmarks.
DataAssigns chart note, splash, and hold-cover asset paths. The visible game-over fields are reserved and currently disabled.
Choose Song Audio

Select one or several files. Recognized Inst/Voices names become the matching stems; common non-OGG formats are converted for the saved copy without renaming the original file.

Save / Ctrl+S

Saves to this song’s assigned folder when one exists; otherwise it uses the normal generated song folder without opening a dialog.

Edit → Choose Saving Folder / Mod

Assigns an output destination to this song. Select an exact chart folder to write there directly, or select a recognized mod root to use <mod>/data/<song-id>. The mod’s song folder is created when needed.

Saved assignment

The resolved destination is remembered by song name in config/fnfmod/chart_editor_save_folders.json. Ctrl+S and Save Events reuse it until Clear Saving Folder is pressed.

Missing destination

If the remembered folder no longer exists, opening the chart displays a foreground warning, clears the invalid assignment, and returns Ctrl+S to the normal generated song folder.

Save As

Asks every time and also accepts either an exact folder or a mod root. The chosen resolved destination becomes this song’s new saved assignment.

File → Import Song to Mod

Creates the named mod template and copies chart, events, metadata, and OGG stems into it. It does not copy arbitrary rich assets.

View

Toggles waveforms, onset markers, instrumental waveform color, Vortex mode, the playtest axis gizmo, and optional playtest transport controls.

F12

Opens the self-contained note preview. It does not build the Minecraft stage and therefore cannot use Free Cam.

Enter / Shift+Enter

Launches full gameplay from the beginning or from the current timeline position. This requires the editor to have been opened from a Funkin’ Machine.

Build a Story Mode week

Select Week Maker in Creator Tools. The preview on the left updates while the fields on the right are edited.

Week ID

Becomes the lowercase JSON filename. Spaces and unsupported characters are converted to hyphens.

Display Name

Is the title shown in Story Mode. If left blank, the Week ID is used.

Songs

Enter existing song IDs separated by commas, in play order. Story Mode starts with the first ID and finishes after the last.

Difficulties

Enter comma-separated difficulty names. A blank list becomes normal.

Choose Image

Selects a PNG for the Story Mode card. Saving copies it into config/fnfmod/mods/images/storymenu/<week-id>.png.

Load Week

Opens an existing Psych week JSON and fills the ID, name, songs, difficulties, visibility toggles, and image source for editing.

Story / Freeplay visibility

Controls whether the week appears in Story Mode and whether its songs may be exposed through Freeplay metadata.

Save

Writes config/fnfmod/mods/weeks/<week-id>.json, copies the image, appends a new ID to weekList.txt, and reloads the song/week libraries.

Map FNF actions to BBS animation

Select Character Editor in Creator Tools. In a bundled mod world it edits that pack’s animations folder; otherwise it edits the global config/fnfmod/mods/animations area.

Player / Opponent

Switches which half of the same character package is being edited. It does not change who the local user controls. Player values go to character.json; meaningful opponent overrides go to character-opp.json. A blank opponent form inherits the player form.

Load...

Opens a searchable list of existing animation packages. Loading restores both the player and opponent definitions, their action mappings, camera offsets, icons, colors, and form choices. If the package bundles a BBS form that is not already installed under the same identity, it is copied into BBS’s Recent category for previewing.

New

Creates an unsaved package with a unique new-character name. Choose its form and mappings before saving.

Character tab

Character name chooses the saved package name. Health icon is the icon identifier, Vocal prefix selects performer-specific Voices filenames, and Character Color supplies the health-bar/waveform color.

Model tab

Selects a BBS form, base model rotation, and base camera X/Y offsets. The Player form can use the currently selected BBS form; the Opponent may inherit it or choose another.

Skin / Model Rules

Player changes allows or locks the user’s Settings override. Authored Skin cycles between the form texture, the current performer’s Minecraft skin/model, and a named Minecraft account when the form supports skin replacement.

Animations tab

Selects an FNF action and maps it to a real BBS state. Per-action camera X/Y values add to the model’s base camera offset. Built-in slots are idle, idle2, four directions, miss, and hey; custom named actions may be added for events or Lua.

Animation selector

Is searchable and scrollable, with a live model preview on the right. Hovering the Anim button and using the wheel changes actions without opening the list. The configured note keys preview directional actions when no text field is active.

Idle: Loop / Bop on beat

Loop lets the BBS state repeat itself. Bop on beat re-triggers the idle using song-style beat timing, including single-idle and alternating idle/idle2 packages.

Save

Writes the player definition and, when used, the opponent definition together. Custom packages are saved as animations/<name>/character.json and character-opp.json; available selected form assets are bundled so the package can work without a separately installed form.

Tune notes, splashes, and hold covers

Select NoteSkin Editor in Creator Tools. Its left panel is a gameplay-style preview; the right panel scrolls through editable choices.

Note Skin / Splashes / Hold Cover

Each opens a searchable chooser with an animated up-lane preview. Current Mod shows assets owned by the active pack; Global shows assets installed for general use. A splash or hold cover embedded by the selected note skin takes priority and disables the separate picker.

Preview Chart

Chooses an installed full-pack song and difficulty. Its chart and audio drive the notes, sustains, splashes, hold covers, timing, pixel UI, and transport bar shown on the left.

Playback controls

Jump to the beginning, move backward/forward five seconds, play or pause, or drag the timeline. Hold Shift while dragging for finer movement.

Skin Uses RGB

Changes whether the selected skin accepts Blockified’s three-color recoloring. This belongs to the skin JSON, not to an individual chart.

Preview UI

Switches the preview between normal and pixel assets without requiring a pixel chart.

Save To

Note’s Path updates the JSON beside the original note assets. Selected Mod Folder opens the modern folder picker and exports the required assets below that mod’s images/noteSkins, images/noteSplashes, and images/pixelUI paths. Blockified Folders installs them into config/fnfmod/skins, config/fnfmod/splashes, and config/fnfmod/splashes/holdSplashes. Existing files with the same names are updated; unrelated files are left alone.

User-settings preview

The editor renders with the user’s currently saved lane colors and timing settings so it shows how the finished skin will look in normal gameplay. Those values are edited from Settings → Note Settings, not here.

Edit Part

Cycles Note, Receptor, Sustain, Splash, and Hold Cover. Scale, alpha, X, and Y are stored in the selected skin’s JSON and update the preview immediately.

Apply / Back

Apply writes or exports the editable skin configuration and its required normal/pixel assets, keeps the selected note, splash, and hold-cover packs as the user’s settings, and leaves the editor open. It also becomes the new rollback point. Back exits and discards only changes made since the latest Apply.

Configure a bundled mod world

World Settings exists only for the singleplayer/LAN host inside a verified bundled mod world.

World tab

Controls cheats, persistence, external content, button visibility, and an automatic uncloseable Lua menu. Choose the machine profile whose menu.lua becomes the world’s main UI.

Gameplay tab

Copies the host’s current gameplay and visual options into the world as forced settings, or clears an existing forced copy. Mods and directory selections are never forced.

Display tab

Keeps the game inside a centered Psych-style 16:9 rectangle, with opaque black letterboxing outside it. Rendering remains at the display’s native resolution and the player’s GUI scale is not changed. The same personal toggle appears in vanilla Video Settings and optional Sodium/Iris replacements.

Assets tab

Bundles assets used by placed BBS model blocks into the world so shared copies can render them without the host’s separate files.

Save & Close / Cancel

Save writes blockified-options.json, reapplies world overrides, and reloads visible content. Cancel discards changes made in this screen.

Edit a machine profile

Hold the Funkin’ Designer and right-click a Funkin’ Machine or virtual hitbox. Profile editing is limited to the singleplayer/LAN host inside a bundled mod world.

Profile list

Clicking a profile previews it on the selected machine immediately. The original profile returns when the screen closes unless Apply, Save As, or a successful Save Profile Changes has committed the selected profile.

Apply

Assigns the selected existing profile to this machine or virtual hitbox.

Save As

Creates a new editable profile folder with machine.json, starter menu.lua, and a textures folder, then assigns it to the machine. Built-in profiles must be saved this way before they can be edited.

Appearance tab

Edits the display name and relative PNG paths. all is the fallback texture; front, back, left, right, top, bottom, and side can override individual faces.

Menu tab

Changes the relative path to the profile’s menu Lua file. It chooses which script loads; it does not edit the Lua source itself.

Behavior tab

Adds, changes, or removes named string, number, and boolean values under behavior. These are profile data for machine-specific code to interpret.

Files tab

Shows the profile folder and explains which files are written. Lua and PNG contents remain separate from machine.json.

Save Profile Changes

Validates relative paths and typed behavior values, writes formatted machine.json, reloads the profile, and keeps its identity.

Reload

Rescans machine files after Lua, PNG, or JSON is changed outside the game.

Place stage objects and author camera events

  1. 1

    Open a machine-based Chart Editor

    Right-click a Funkin’ Machine, press 8, and select Chart Editor. Opening it with the command does not provide the stage anchor required by the full playtest.

  2. 2

    Launch full gameplay

    Press Enter to start at the beginning or Shift + Enter to start at the current chart position. Do not use F12; that is only the note preview.

  3. 3

    Toggle Free Cam

    During the playtest press Ctrl + Shift + Space. The same shortcut or the menu’s Exit button leaves Free Cam.

Objects → Add object

Creates a Sprite, Sparrow XML Spritesheet, Graph, 2D character, 3D character, or Text object at the current view.

Objects → Existing objects

Refreshes and selects live Lua objects plus main or extra characters. Editing is linked to the runtime object, so transforms update the actual stage object rather than making an unrelated duplicate.

Selected object controls

Choose its PNG/JSON/text/color, animation and FPS where relevant, and modifiers such as billboard, lighting, see-through rendering, and antialiasing. Runtime-linked tags stay fixed so Lua references remain valid.

G / R / S

Moves, rotates, or scales the selected object. Type a number for an exact value; X/Y/Z constrain axes, Shift slows motion, Ctrl snaps, Alt+G/R/S resets, and click/Enter confirms. Press R twice for trackball rotation.

Numpad .

Frames the selected object’s actual origin in the camera. Delete removes an editor-created object or stops editing a linked runtime object.

Camera → Movement

Override authors a position fixed to the machine anchor. Attached authors a position relative to the currently focused character.

Camera → Frame

Machine expresses XYZ using the machine’s facing. Camera uses the current view axes. The P and R rows and Zoom accept typed values for precise placement.

Camera mode

Normal copies a fixed camera pose. Orbit adds a pivot: Pinned stores a world-relative point, while Follow Focus stores an XYZ offset from the player/opponent focus. Camera Rotation 3D can then animate around that pivot.

Viewport navigation

Hold left click in empty space to fly/look, or start with Shift+click to move through an object. Middle mouse orbits, Shift+MMB pans, Ctrl+MMB dollies, and the wheel dollies unless the fly cursor is grabbed, when it changes fly speed.

Ctrl+C / Ctrl+V

Ctrl+C copies the selected object as complete ready-to-paste Lua. With no selection it copies the camera event set for the Chart Editor. Ctrl+V duplicates supported world-object Lua only when the generated first-line type comment is present.

F1

Shows the complete in-game Free Cam key reference, including undo/redo, roll, zoom, speed modifiers, menu visibility, and transform confirmation/cancel keys.

Reference / Commands

Commands

/fnf editor [song]

Opens the Chart Editor, optionally loading an exact song ID.

/fnf reload

Reloads options, songs, machines, icons, animations, skins, splashes, hitsounds, fonts, and scores.

/fnf reload songs|skins|splashes|animations|icons|hitsounds|fonts|options|scores

Reloads one content group.

/fnf world export <pack>

Moves the current save into the selected pack’s bundled worlds and reopens it there.

/fnf world import

Moves the active bundled world back into normal Minecraft saves.

AuthorityFNF commands require permission level 2: cheats in singleplayer or operator permission on a server.
Reference / Compatibility

Compatibility boundaries

Implemented

Psych-style charts, V-Slice chart/metadata pairs, Codename modern charts, Psych events, weeks, stage/character JSON, Sparrow XML, Adobe Animate atlases, custom events/note types, and broad Psych Lua behavior.

Graceful no-op

GLSL shader setters, HScript APIs, video/dialogue playback, arbitrary Haxe/class invocation, Flixel group mutation, controller input, loadSong, and script-driven countdown start are accepted but do not execute.

Sandboxed

Lua has no OS, environment, Java, package loading, unrestricted filesystem, or dynamic-code access. Each callback is capped at 5,000,000 Lua instructions and one second of Lua wall time; trusted host work does not consume the wall limit.

Dedicated servers

Gameplay Lua and rich executable assets are disabled. Chart, events, and audio remain playable through validated server transfer and cache.

Supported easing bases are Smooth, Sine, Cubic, Quint, Circ, Elastic, Quad, Quart, Expo, Back, Bounce, Linear, and Constant, with in, out, and inOut directions.
