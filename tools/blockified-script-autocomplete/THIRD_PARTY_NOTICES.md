# Upstream attribution

This extension adapts the Psych Engine 1.0 completion database and the completion/hover/signature-help idea from [Funkin Script AutoCompleter](https://github.com/Snirozu/Funkin-Script-AutoComplete), by Snirozu and its contributors. Its upstream `data/psych_1.0.json` is retained as generator input; entries are filtered to APIs registered by Blockified, with Blockified-specific entries added. The distributed extension contains the generated subset, not the original extension's executable code.

Upstream's `LICENSE` file is included unchanged. The upstream project calls it “Apache NON-AI License, Version 2.0”; this extension is a derivative of its API data, not an official Snirozu release. Blockified's own API signatures and descriptions were verified against the local mod source.
